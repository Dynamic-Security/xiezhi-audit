# 报告措辞规范

- 摘要先写审计范围与版本、是否完整；partial 时逐条列出原因。
- 每条漏洞用一句话说明“谁、通过什么入口、能做什么”，避免夸大。
- 严重度描述：严重 = 无需认证即可远程执行代码或获取大量数据；高 = 需要普通用户权限即可越权或注入；中 = 需要特定条件；低 = 影响有限。
- 修复建议标明“由 AI 生成，需人工确认”。
